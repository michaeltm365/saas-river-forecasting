# Experiment archive

Branch `correction-sep11` preserves experimental code, configurations, reports, and logs as of September 14, 2026. `artifacts.json` records the SHA-256 and size of every local retraining artifact. Large data remain on the original project host under `data/retrain/`; they are not stored in GitHub. A separate checkpoint backup is under `data/experiment_archives/2026-09-14/checkpoints.tar.gz`. Keep this host storage available for archived runs. Private paper drafts remain excluded from Git.
